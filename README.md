# 뮤스 (Mews) · Musical News

> 좋아하는 뮤지컬의 최신 소식을 한눈에 확인하세요.

좋아하는 뮤지컬 작품명을 검색하면 **Google 뉴스**에서 실시간 관련 뉴스를 가져와
요약과 함께 파스텔 톤 카드로 보여주는 웹앱입니다. (뮤지컬 News)
백엔드 서버 없이 **Netlify Functions** 만으로 CORS 제약 없이 동작합니다.

## 주요 기능

- 작품명 검색 시 자동으로 `" 뮤지컬"` 키워드를 붙여 검색 품질 향상
- 카드별 **기사 요약(리드)** 표시
  - 구글 뉴스의 암호화 링크를 `batchexecute`로 **원문 URL로 해석**
  - 원문 기사의 메타 설명/첫 문단을 추출해 대략적 내용 파악 지원
- **더보기** 방식의 점진적 로딩 (한 번에 9개씩)
- **정렬**(최신순 / 오래된순), **결과 내 재검색**, **초기화** 지원
- 시간대 변형 쿼리를 병합·중복 제거하여 더 많은 기사 확보
  (Google 뉴스 RSS의 피드당 100개 한계를 보완)
- 제목 끝의 `" - 언론사명"` 자동 제거 / 날짜 `YYYY년 MM월 DD일` 변환
- KRDS 가이드라인을 고려한 명확한 포커스 상태 / 접근성

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 마크업 구조 (헤더 · 검색 · 결과 · 푸터) |
| `style.css` | 파스텔 디자인 시스템 및 반응형 스타일 |
| `app.js` | 검색 · 정렬 · 더보기 · 결과 내 검색 · 초기화 · 요약 로딩 |
| `favicon.svg` | 파비콘 (밤하늘 + 별빛 모티브) |
| `netlify/functions/news.js` | 구글 뉴스 수집 · 병합 · 중복 제거 (JSON 반환) |
| `netlify/functions/summary.js` | 원문 링크 해석 후 기사 요약 추출 |
| `netlify.toml` | Netlify 배포 / Functions 설정 |

## 배포 방법

1. 이 저장소를 Netlify에 연결합니다. (빌드 명령 없음, 발행 디렉터리 `.`)
2. 배포가 끝나면 발급된 도메인에서 바로 사용할 수 있습니다.

> ℹ️ 뉴스/요약은 Netlify Functions에서 동작하므로 **로컬에서 단순히 `index.html` 을 열면
> 동작하지 않습니다.** `netlify dev` 또는 배포 환경에서 확인하세요.

```bash
# 로컬 확인 (Netlify CLI 필요)
npx netlify dev
```
