# 뮤스 (Mews) · Musical News

> 궁금한 뮤지컬의 최신 소식을 한눈에 확인하세요.

궁금한 뮤지컬 작품명을 검색하면 **네이버 뉴스 검색 API**와 **국내 신문사 공식 RSS**를
합쳐 실시간 관련 뉴스를 가져와, **공식 요약**과 함께 파스텔 톤 카드로 보여주는
웹앱입니다. (뮤지컬 News) 백엔드 서버 없이 **Netlify Functions** 만으로
CORS 제약 없이 동작합니다.

## 데이터 출처 & 저작권

뮤스는 **본문을 직접 크롤링하지 않고**, 각 제공처가 공개·배포한 정보만 사용합니다.

| 경로 | 사용 데이터 | 비고 |
| --- | --- | --- |
| **네이버 뉴스 검색 API** | 제목 · 원문 링크 · **공식 스니펫(요약)** · 발행일 | 1순위. API가 제공하는 공식 데이터 |
| **국내 신문사 공식 RSS** | 제목 · 원문 직링크 · **공식 요약(description)** · 발행일 | 매체가 배포(syndication) 목적으로 공개한 피드 |
| 구글 뉴스 RSS | 제목 · 링크 · 발행일 | **폴백 전용** (네이버 키 미설정/호출 실패 시에만) |

- 각 카드에는 **데이터를 가져온 경로 배지**(네이버 검색 / 공식 RSS / 구글 뉴스)가
  표시되어 출처와 신빙성을 한눈에 구분할 수 있습니다.
- 같은 기사가 여러 경로에 있으면 **신문사 공식 RSS(직링크·풀요약)** 를 우선합니다.

## 주요 기능

- 작품명 검색 시 자동으로 `" 뮤지컬"` 키워드를 붙여 검색 품질 향상
- 카드별 **공식 요약** 표시
  - 네이버 검색 API 스니펫은 **전문(全文) 그대로** 표시 (잘림 없음)
  - 신문사 RSS 요약으로 보강
- **출처 경로 배지**(브랜드 아이콘)로 네이버 / 공식 RSS / 구글 뉴스 구분 표시
- **출처 필터** — 네이버 / RSS / 구글을 **다중 선택**해 원하는 출처만 보기
- 네이버 검색 결과를 **페이지네이션으로 최대치까지 수집**(100개 제한 없음, API 상한 1000개)
- **더보기** 방식의 점진적 로딩 (한 번에 9개씩)
- **정렬**(최신순 / 오래된순), **결과 내 재검색**, **초기화** 지원
- 제목 끝의 `" - 언론사명"` 자동 제거 / 날짜 `YYYY년 MM월 DD일` 변환
- **라이트 / 다크 테마** 전환 (시스템 설정 자동 감지 · 선택 저장 · 깜빡임 방지)
- **최근 검색어 / 인기 작품 칩** — 인트로 화면에서 한 번에 검색 (localStorage)
- 검색 로딩 시 **스켈레톤 카드**, 카드 진입 **스태거 애니메이션**, **맨 위로** 버튼
- KRDS 가이드라인을 고려한 명확한 포커스 상태 / 접근성

## 환경변수 (네이버 검색 API)

`netlify/functions/news.js` 는 다음 환경변수를 읽습니다. **키는 코드/리포지토리에
두지 않고** Netlify 환경변수 또는 로컬 `.env`(커밋 안 됨)에만 보관하세요.

| 변수 | 설명 |
| --- | --- |
| `NAVER_CLIENT_ID` | 네이버 개발자센터 애플리케이션 Client ID |
| `NAVER_CLIENT_SECRET` | 네이버 개발자센터 애플리케이션 Client Secret |

- 발급: <https://developers.naver.com> → 애플리케이션 등록 → **검색** API 추가
- Netlify: Site configuration → Environment variables 에 두 값 추가 후 **재배포**
- 로컬: `.env.example` 를 복사해 `.env` 생성 후 `netlify dev`
- 미설정 시에도 앱은 동작하며 구글 뉴스 RSS로 폴백됩니다.
- 정상 연결 확인: `/.netlify/functions/news?q=위키드%20뮤지컬` 응답의 `"source":"naver"`

> 신문사 RSS 피드 목록은 `news.js` 상단 `PUBLISHER_FEEDS` 배열에서 자유롭게
> 추가/삭제할 수 있습니다. 일부 피드가 실패해도 나머지로 계속 동작합니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 마크업 구조 (헤더 · 검색 · 결과 · 푸터) |
| `style.css` | 파스텔 디자인 시스템 및 반응형 스타일 |
| `app.js` | 검색 · 정렬 · 더보기 · 결과 내 검색 · 초기화 · 카드 렌더링 |
| `favicon.svg` | 파비콘 (밤하늘 + 별빛 모티브) |
| `netlify/functions/news.js` | 네이버 뉴스 검색 API + 신문사 공식 RSS 수집 · 보강 · 중복 제거 (JSON 반환) |
| `netlify.toml` | Netlify 배포 / Functions 설정 |
| `.env.example` | 환경변수 템플릿 (실제 `.env` 는 커밋되지 않음) |

## 배포 방법

1. 이 저장소를 Netlify에 연결합니다. (빌드 명령 없음, 발행 디렉터리 `.`)
2. **환경변수**(`NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`)를 등록합니다.
3. 배포가 끝나면 발급된 도메인에서 바로 사용할 수 있습니다.

> ℹ️ 뉴스/요약은 Netlify Functions에서 동작하므로 **로컬에서 단순히 `index.html` 을 열면
> 동작하지 않습니다.** `netlify dev` 또는 배포 환경에서 확인하세요.

```bash
# 로컬 확인 (Netlify CLI 필요)
npx netlify dev
```
