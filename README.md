# 뮤스 (Mews) · Musical News

> 별빛 사이에서 당신의 뮤지컬 이야기를 찾아드려요.

좋아하는 뮤지컬 작품명을 검색하면 **구글 뉴스 RSS**에서 실시간 관련 뉴스를 가져와
'어린왕자' 모티브의 따뜻한 파스텔 카드로 보여주는 정적 웹앱입니다.
백엔드 서버 없이 **Netlify 프록시(`_redirects`)** 만으로 CORS 제약 없이 동작합니다.

## ✨ 주요 기능

- 작품명 검색 시 자동으로 `" 뮤지컬"` 키워드를 붙여 검색 품질 향상
- 한국 · 해외 작품을 섞은 추천 키워드 태그 (랜덤 제공)
- 구글 뉴스 RSS XML 파싱 → 제목/출처/발행일/원문 링크 카드화
  - 제목 끝의 `" - 언론사명"` 자동 제거
  - RFC 822 날짜를 `YYYY년 MM월 DD일` 형식으로 변환
- "은하수 탐색 중..." 감성 로딩 상태, 빈 결과·오류 안내
- KRDS 가이드라인을 고려한 명확한 포커스 상태 / 접근성

## 🗂 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 마크업 구조 (헤더 · 검색 · 결과 · 푸터) |
| `style.css` | 파스텔 디자인 시스템 및 반응형 스타일 |
| `app.js` | 검색 · 프록시 fetch · XML 파싱 · 렌더링 로직 |
| `_redirects` | Netlify 프록시 규칙 (구글 뉴스 RSS) |
| `netlify.toml` | Netlify 배포/리다이렉트 설정 |

## 🚀 배포 방법

1. 이 저장소를 Netlify에 연결합니다. (빌드 명령 없음, 발행 디렉터리 `.`)
2. 배포가 끝나면 발급된 도메인에서 바로 사용할 수 있습니다.

> ℹ️ 프록시는 Netlify 인프라에서 동작하므로 **로컬에서 단순히 `index.html` 을 열면
> `/google-news/` 요청이 동작하지 않습니다.** `netlify dev` 또는 배포 환경에서 확인하세요.

```bash
# 로컬 확인 (Netlify CLI 필요)
npx netlify dev
```
